feat(example-verification): C12 -- JavaRunner: the third LanguageRunner protocol implementation (tier 1-3)

New scripts/pipeline/lib/example_verification/runners/java.py:
JavaRunner, the third concrete runners/base.py LanguageRunner
implementation after C5's GoRunner and C11's DotNetRunner, applying both
those taskcards' independent-review lessons from the start:

- canonical_lang="java", ceiling_tier=3.
- starts_chain: first non-comment line is import/package/class.
- acquire: real toolchain discovery via `mvn -version`, parsing its own
  reported Java version/runtime line. Real, machine-confirmed wrinkle:
  `mvn` on this machine resolves its own build against JDK 17.0.19, while
  the bare `java` on PATH is a DIFFERENT JDK, 21.0.11 -- confirmed live
  before writing any code. Uses shutil.which("mvn") (never a bare "mvn"
  argv, which raises WinError 2 on Windows since mvn resolves to
  mvn.CMD -- also confirmed live).
- compile/execute: real javac/java (not full mvn per block -- mvn builds
  once, javac/java do the fast per-block smoke test, per the plan's own
  foss-java-publish.md-derived design).
- classify: a file-citation-basename check parameterized by the block's
  own actual generated filename ({class_name}.java, not a fixed constant
  -- a block that's already a complete `class X` declaration keeps its
  own name). Verified against two real, distinct Java diagnostic formats
  confirmed via a manual probe before writing any code (including a
  genuine cross-class runtime exception): javac's own
  "<file>.java:<line>:" and a stack frame's "(<file>.java:<line>)".
