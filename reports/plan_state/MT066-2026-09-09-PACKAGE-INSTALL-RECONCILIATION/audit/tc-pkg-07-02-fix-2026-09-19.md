### W4 decision on the merits

`package-install-inline` renders only `git clone <repo>.git` for an unpublished package (inline mode by design). A sentence
`Install it with git clone ...` gives a reader an incomplete instruction. The block-level `package-install` renders the full
clone / cd / `pip install -e .` sequence today and the registry command once published, so it stays correct in both states.
This is the same shortcode the three code-block edits of TC-PKG-07-02 already used in blog posts.

## Findings for the supervisor (not fixed here)

   numbers are routinely off (here by 1 after the final grade write; by 32 in the version committed by 3c5b8e804e). This masks EG_GROUNDING wherever
   a section has code and no evidence API; a regeneration unmasks it. It is a fixed-point bug in the grade/evidence write order.
2. `attach_evidence.py --force` also writes its own `grade:` from a reduced evaluator set (it wrote `A / No findings` on the font
   installation page whose full-evaluator grade is B). Stored grades are only trustworthy after `content_eval --write-grade`.

   not check-only (already known from TC-PKG-07-02).
