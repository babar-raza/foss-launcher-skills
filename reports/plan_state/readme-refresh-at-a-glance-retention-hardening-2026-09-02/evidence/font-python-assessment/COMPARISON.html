7. What is not better, or not resolved

Length. 2.5× the prose and 1,031 lines. That is the portfolio template's shape, but it is a real cost for a reader who wants the 487-line version's brevity, and a larger surface to keep true on every release.
Six heading names and two tables are gone. Content is retained (§3, §4), but a reader who navigates the live README by "Capability Snapshot" or "CLI Highlights" will not find those names, and the two comparison tables became bullets.
One judgment-call exclusion. The roadmap paragraph (u0028) is dropped as non-checkable positioning. Defensible, but it is the one piece of the live document's voice the candidate does not carry.
Installation will go stale the day the package ships to PyPI. Today "not yet published" is true; the candidate names the future command so the fix is one line, but it is a fact that changes outside this repo.
17 real subcommands are demonstrated in neither document (estimate, glyphs, metrics, report, stage, sync-completed, preview-batch, preview-grid, the three preview-animation-path*, var-batch, the three var-delta-*-board, web-batch, web-optimize). Parity with live, not an improvement.
Publication target. The repository is a weekly re-snapshot from GitLab with 22 orphan roots and a single commit on main; a GitHub PR there does not survive the next snapshot. That is the reason publication is undecided, independent of the candidate's quality.
