# Governance Friction Scorecard

Quantitative assessment of each governance mechanism.
Generated by TC-GOV-10 (Governance Simplification Sprint v3).

## Rating Scale

- **Safety Value** (1-5): How critical is this check for preventing real damage?
- **False Positive Risk** (1-5): How often does it block legitimate work?
- **Runtime Cost**: fast (<1s), medium (1-5s), slow (>5s)
- **Blocking Frequency**: never / rare / occasional / frequent
- **Recovery Clarity**: clear (error says what to do) / unclear / none
- **Audit Quality**: full (logged + traceable) / partial / none
- **Verdict**: keep / simplify / monitor / remove
