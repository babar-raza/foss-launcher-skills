## Override Token System

| Component | Purpose | Audit Trail | How to Use |
|-----------|---------|-------------|------------|
| `scripts/pipeline/override_manager.py` | Create time-limited override tokens for forbidden paths | Token file + post-commit archive | `python scripts/pipeline/override_manager.py create --path <file> --reason "<reason>"` |
| `scripts/post-commit-override.sh` | Consume override tokens after commit | Archives consumed tokens | Automatic (post-commit hook) |
| Override token directory | `reports/overrides/tokens/` | Token files contain reason + expiry | Created by override_manager, consumed by post-commit |

## Bypass Classification

| Class | Description | Examples |
|-------|-------------|----------|
| **A** (No bypass) | Strict blocker, no exception path | Filename conventions, frontmatter validation, reports/ boundary |
| **B** (Token only) | Override token required, human-authorized | Path guard forbidden paths (AGENTS.md, CLAUDE.md, themes/, layouts/) |
| **C** (Env bypass) | Environment variable bypass available | Session gate, content edit, skill context, content write, py placement |
| **D** (Warning) | Non-blocking advisory | content_hash normalization, last_mechanism staleness |

## Prohibited Bypass Methods

| Method | Why Prohibited | Reference |
|--------|---------------|-----------|
| `--no-verify` | Skips ALL hooks; breaks audit trail completely | AGENTS.md line 1981 |
| `git commit --amend` (to avoid hooks) | Rewrites history; not a bypass mechanism | AGENTS.md prohibited actions |
| Direct `.git/hooks/` modification | Tampering with installed hooks | Hooks are repo-managed; reinstall with `bash scripts/install-hooks.sh` |
