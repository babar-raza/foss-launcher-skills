High-level areas:

- `content/` contains generated Hugo content.
- `knowledge/` contains extracted and promoted product truth.
- `scripts/pipeline/` contains pipeline commands and libraries.
- `scripts/ci/` contains CI validators and hooks.
- `docs/` contains this documentation set.
- `reports/` contains local evidence and run outputs.
