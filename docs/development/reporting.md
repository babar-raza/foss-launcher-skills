## Rules

- Put task reports under `reports/` unless the user requests an audit artifact under `docs/_audit/`.
- Include what changed, why, verification commands, and known gaps.
- Link to canonical docs instead of restating reference tables.
- Do not move report content into active docs unless it is durable and code-backed.
