# .governance/ — Cross-Agent Capability Governance

This directory contains the formal governance layer for cross-agent capability parity in
the `foss-launcher-skills-gitlab` repository.

## Purpose

Every governed capability available to one supported agent (Claude Code, Codex, KiloCode,
generic agents) must be discoverable and executable by every other supported agent, subject
to the same contract, validation, and authority.

This directory formalizes that guarantee with schemas, generated reports, and supplemental
agent discovery indexes.

## Canonical Source of Truth

**The canonical source of truth for all capabilities is `skills/registry.yaml`.**

This directory extends that registry with:
- Rich capability contract metadata (`.governance/capabilities/registry.yaml`)
- JSON schemas for contracts, receipts, and adapter manifests (`.governance/schemas/`)
- Generated parity and drift reports (`.governance/generated/`)
- Supplemental agent discovery indexes (`.governance/*_CAPABILITY_INDEX.md`)
- Pilot evidence records (`.governance/pilots/`)

## Directory Structure

```
.governance/
  capabilities/
    registry.yaml              # Capability contract registry (extends skills/registry.yaml)
  schemas/
    capability.schema.json     # JSON Schema for capability contracts
    execution-receipt.schema.json
    adapter-manifest.schema.json
  generated/
    baseline.yaml              # Baseline capture from last sync
    parity-report.yaml         # Generated by tools/capability_sync/validate_semantic_parity.py
    drift-report.yaml          # Generated by tools/capability_sync/detect_adapter_drift.py
    claude-command-manifest.yaml
    agent-skill-manifest.yaml
  pilots/
    README.md                  # Pilot evidence index (15 required pilots)
  CLAUDE_CAPABILITY_INDEX.md   # Generated capability index for Claude Code agents
  CODEX_CAPABILITY_INDEX.md    # Generated capability index for Codex/generic agents
  AGENTS_CAPABILITY_INDEX.md   # Generated capability index for AGENTS.md (human review)
  README.md                    # This file
```

## Synchronization

To synchronize all adapters and regenerate reports:
```bash
.venv/Scripts/python tools/capability_sync/run_sync.py
```

Or via skill:
```
/sync-capabilities
```

To validate parity without making changes:
```bash
.venv/Scripts/python tools/capability_sync/validate_semantic_parity.py --check
.venv/Scripts/python tools/capability_sync/detect_adapter_drift.py --check
```

## Human Maintainer Notes

### AGENTS.md
The `.governance/AGENTS_CAPABILITY_INDEX.md` file contains a generated capability discovery
section intended for inclusion in `AGENTS.md`. Because `AGENTS.md` is protected (forbidden
write path, human-maintained), human maintainers must review and manually incorporate this
content as appropriate.

### CLAUDE.md / CODEX.md
Similarly, `.governance/CLAUDE_CAPABILITY_INDEX.md` and `.governance/CODEX_CAPABILITY_INDEX.md`
contain generated indexes for those files. They are protected write paths and must be updated
by human maintainers or via `--no-verify` override during CI-controlled release operations.

## Generated File Markers

All generated content in this directory uses stable boundary markers:
```
<!-- BEGIN GENERATED CAPABILITY INDEX -->
<!-- Generated by: tools/capability_sync/generate_capability_index.py -->
<!-- DO NOT EDIT MANUALLY — run /sync-capabilities to regenerate -->
...
<!-- END GENERATED CAPABILITY INDEX -->
```

Do not edit content inside these markers manually. Run `/sync-capabilities` to regenerate.
